# What Does Data Analysis Include?

Data analysis involves several key areas:

- **Data Analysis:** Examining, cleaning, and interpreting data to identify patterns, trends, and meaningful insights.
- **Data Visualization (Data Viz):** Presenting data through charts, graphs, and other visual formats to make information easier to understand and communicate. Data visualization is an essential part of data analysis because it often reveals insights that may not be immediately apparent in raw data.
- **Data Modeling (Predictive Analysis):** Using historical data to develop models that identify patterns and predict possible future outcomes.


## Analytics

- **Data analytics** is a term often used interchangeably with data analysis and data visualization, although its meaning can vary depending on the context.
- **Business Analytics:** Focuses on analyzing business-related data to support decision-making, improve performance, and identify business opportunities.


## Data Science

**Data science** is a broader field that builds upon data analysis and incorporates more advanced techniques, such as:

- Data mining
- Machine learning
- Deep learning
- Artificial intelligence (AI)

These techniques help uncover complex patterns, automate processes, and develop systems that can learn from data and make predictions.
